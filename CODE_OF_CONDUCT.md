# Code of Conduct

## Our commitment

This project exists to build a careful, well-engineered tool. Everyone
participating in the project — issues, discussions, pull requests, reviews — is
expected to keep the exchange professional and respectful regardless of
background, identity, experience level or body of expertise.

## Expected behavior

- Critique code and designs, not people.
- Prefer precise, good-faith technical arguments over emphasis.
- Assume competence and good intent; ask before concluding bad intent.
- Accept that "no" to a feature is often a scope decision, not a judgment.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing others' private information without consent.
- Sustained disruption of discussions after a moderator has asked it to stop.
- Sharing traces, fixtures or logs containing secrets or personal data.

## Enforcement

Maintainers may remove, edit or reject contributions and comments that violate
this code, and may temporarily or permanently ban contributors for serious or
repeated violations. Report problems to the maintainers via GitHub (or a
private security advisory if the report itself is sensitive).

Maintainers who do not follow or enforce this code in good faith face the same
consequences as any other contributor.

This code of conduct is adapted in spirit from the Contributor Covenant.
